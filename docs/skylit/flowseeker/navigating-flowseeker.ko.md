# Flowseeker 화면 탐색 가이드: Live Feed, Scanner, Tracker

> **번역 안내:** Skylit의 화면 기능·수치·표·메뉴명을 원문에 맞춰 옮겼습니다. UI는 서비스 버전에 따라 달라질 수 있습니다. [영어 원문](navigating-flowseeker.md)

**Flowseeker · 원문 약 12분**

## 서로 연결되는 세 페이지

Flowseeker는 한 화면으로 끝나지 않습니다. 사이드바의 FLOWSEEKER에는 원문 기준 **Live Feed, Dark Feed, Flow Scanner, Flow Compass, Contract Lookup, Company Events, Flow Tracker, Flow Alerts**의 **8개 페이지**가 있습니다. [Flowseeker 입문](https://www.skylit.ai/learn/intro-to-flowseeker)은 실시간 피드를 자세히 설명했고, 이 글은 긴밀하게 연결되는 세 페이지를 다룹니다. 목적을 구분하면 UI를 헤매는 대신 효율적으로 사용할 수 있습니다.

- **Live Feed:** 거래가 체결되는 대로 한 건씩 흘러가는 **실시간 테이프**입니다.
- **Flow Scanner:** 하루의 거래를 **옵션 계약 단위**로 모아 보여주는 화면입니다. 동일한 티커·만기·행사가·콜/풋의 모든 체결을 하나의 행으로 집계합니다.
- **Flow Tracker:** 관심 있는 체결을 **북마크**해 나중에 손익과 청산 추정 상태를 확인하는 목록입니다.

세 화면은 기본 데이터와 상세 차트 모달을 공유합니다. 다른 점은 **분석 단위**입니다. Live Feed는 개별 체결, Scanner는 하루의 계약별 합계, Tracker는 저장한 체결의 이후 경과를 보여줍니다.

> 🎯 **쉽게 이해하기**  
> Live Feed는 거래가 하나씩 찍히는 전광판, Scanner는 각 계약의 하루 성적표, Tracker는 나중에 다시 볼 거래를 적어 두는 공책입니다. 데이터는 같아도 보여주는 방식은 다릅니다.

## 화면으로 이동하는 방법

데스크톱에서는 세 페이지가 왼쪽 **FLOWSEEKER** 섹션에 있습니다. 원문은 **Live Feed(라디오 아이콘), Flow Scanner(돋보기 아이콘), Flow Tracker(레이더 아이콘)**로 표시한다고 설명합니다.

모바일에서는 Flowseeker 바에 **Live Feed, Dark Feed, Flow, Compass, Lookup, Events, Tracker, Alerts**라는 짧은 메뉴명이 표시됩니다. Discord 또는 API 권한이 있는 계정은 **Settings** 메뉴도 볼 수 있으며, Discord 채널, 요약 섹션 및 API 관련 설정을 다룰 수 있다고 원문은 안내합니다.

## Live Feed: 실시간 개별 체결

Live Feed는 옵션 체결이 발생할 때마다 새 행이 추가되는 화면입니다. 빠르게 움직이는 시장을 읽는 데 맞춰져 있습니다.

### 탭으로 여러 관점을 만들기

Live Feed에는 최대 **10개의 탭**을 만들 수 있다고 원문은 설명합니다. 각 탭마다 이름, 필터, 열 표시·순서, 강조 규칙을 별도로 관리할 수 있습니다. **“고확신 스윕”** 탭과 **“전체 피드”** 탭을 동시에 열어도 서로 영향을 주지 않습니다.

탭은 이름을 바꾸거나 복제할 수 있습니다. 하나의 설정을 만든 뒤 복제하고 프리미엄 최소값이나 특정 티커만 달리해 비교하면 효율적입니다. 탭별로 **히스토리 모드**를 설정해 과거 체결을 살펴보는 방식도 지원한다고 설명합니다.

### 티커 검색과 제외

특정 종목만 보고 싶다면 검색 기능에 티커를 넣습니다. 반대로 **`!SPY`**와 같이 느낌표를 앞에 붙이면 SPY 거래를 제외할 수 있습니다. 이런 태그 필터는 필요한 순간에 추가하고 제거할 수 있어 복잡한 필터 패널을 반복해서 여는 수고를 줄입니다.

개별 체결 행에서 우클릭하면 해당 티커·만기만 표시하거나 특정 시끄러운 티커를 제외하는 등의 **빠른 필터**를 적용할 수 있습니다.

### 열과 강조 규칙 관리

열 설정에서는 사용하지 않는 열을 숨기거나 순서를 바꿀 수 있습니다. 모든 **22개 열**을 처음부터 볼 필요는 없습니다. 기본 판단에 도움이 되는 종목, 체결 위치, 프리미엄, Flow Score, DTE 등을 앞쪽에 놓고 시작하세요.

**Flow Highlighting**은 조건에 맞는 행을 시각적으로 강조합니다. 예를 들어 **V/OI > 2.0**인 체결을 따로 표시하는 규칙을 만들 수 있다고 설명합니다. 탭마다 규칙이 달라 한 탭은 특정 스윕을 강조하고 다른 탭은 전부 보여주도록 구성할 수 있습니다.

### 현재 화면 공유하기

헤더의 **Share** 버튼에는 원문 기준 **Copy Image**, **Save Image**가 있습니다. 현재 탭 이름과 적용된 필터, 보이는 행을 **PNG**로 캡처해 Slack이나 Discord 등에 전달할 수 있습니다.

이는 피드 전체의 스냅샷을 공유하는 기능입니다. **개별 거래와 관련 차트를 Discord로 공유하는 기능**은 아래의 차트 모달 안에 있습니다.

### 다중 레그 전략 모달

수직 스프레드, 스트래들, 아이언 콘도르처럼 여러 옵션 계약을 한 번에 활용하는 **다중 레그 전략**의 체결에는 **Layers 아이콘**이 표시됩니다. 한 레그만 보면 전체 전략의 방향을 잘못 판단하기 쉽습니다.

Layers 아이콘 또는 행의 전략 배지를 클릭하면 관련 레그를 모아 보여주는 모달이 열립니다.

- **전략 유형과 레그 수:** Vertical Spread, Iron Condor, Strangle 등의 이름
- **거래 요약:** 전체 순프리미엄, 총 계약 수량, 행사가 범위, 강세·약세·중립으로 표시되는 순센티먼트
- **Strike Structure:** 가로축의 행사가별로 각 레그를 배치한 구조도. 풋 크레딧 스프레드는 가까운 행사가의 두 풋, 스트랭글은 낮은 행사가의 풋과 높은 행사가의 콜, 아이언 콘도르는 네 레그로 구분할 수 있습니다.
- **레그별 차트:** 각 개별 계약이 이후 어떻게 거래됐는지 확인하는 차트

모르는 체결의 레그 하나만 보는 것과 **전체 포지션의 구조와 각 계약의 이후 흐름을 함께 보는 것**은 분석의 질이 다릅니다. 원문은 **Escape**로 모달을 닫을 수 있다고 안내합니다.

### 차트에서 Expand Trades로 돌아오기

Live Feed의 행을 클릭해 차트 모달을 연 뒤 **특정 캔들을 선택하고 Expand Trades**를 누르면, 그 캔들의 종목·행사가·만기·시간대에 해당하는 체결만 보여주는 **새 Live Feed 탭**이 만들어집니다.

예를 들어 **10시 47분**의 특정 캔들을 만든 거래가 궁금하다면 매번 수동으로 필터를 설정하지 않고 해당 캔들의 개별 체결을 볼 수 있습니다. 이 동작은 **Live Feed 전용**이며 Scanner에서는 지원되지 않는다고 설명합니다.

## Flow Scanner: 하루 거래를 계약별로 집계

Scanner는 탭·필터·표가 있다는 점에서 Live Feed와 비슷해 보이지만 분석 단위는 완전히 다릅니다.

**Live Feed**에서는 한 행이 **개별 체결**입니다. SPY의 **580달러 콜 2,000계약**에 대한 스윕은 거래소와 체결 단위에 따라 **3건·5건·10건**으로 표시될 수도 있습니다.

**Scanner**에서는 동일 계약이 **한 행**입니다. 그 안에 당일 총거래량, 총프리미엄, 체결 수, 매수·매도호가 비중, 방향성 점수, 미결제약정 변화, 스윕·복합 전략 비중 등이 합쳐집니다. **오늘 어떤 옵션 계약에서 실제 거래가 집중됐는지** 파악하기 위한 화면입니다. 상단 날짜 선택기로 과거 거래일도 살펴볼 수 있습니다.

| 기능 | Live Feed | Flow Scanner |
| --- | --- | --- |
| 분석 단위 | 체결 한 건씩, 실시간 | 계약별 하루 집계 |
| 최대 탭 수 | **10개** | **5개** |
| 날짜 선택 | 과거 모드 선택 | 거래일 이전·다음·달력 |
| 필터 | 프리미엄·자산 유형·스윕·Flow Score·DTE·실적·섹터·Side | 기본 필터 + OI 증가·계약/체인 센티먼트·행사가 범위·OTM/ITM/0DTE·OPEX Only |
| Flow Highlighting | 탭별 사용 가능 | 원문 기준 미지원 |
| 열 관리 | 표시·숨김·드래그 정렬 | 드래그 정렬 |
| 우클릭 | 추적, 유사 체결 표시·제외, 요약 추가 | 권한에 따라 요약 추가 |
| Expand Trades | 새 Live Feed 탭 생성 | 원문 기준 미연결 |
| 공유 | 이미지 내보내기 | 이미지 내보내기 |

### Scanner의 행에서 읽을 정보

각 행은 특정 계약의 하루 전체를 요약합니다.

- **총프리미엄·거래량·체결 수:** 실제 활동이 얼마나 많았는지
- **Bid / Ask 체결 비중:** 당일 거래량의 몇 퍼센트가 매수호가, 매도호가, 중간에서 체결됐는지. 예를 들어 **Ask 80%**와 **Bid 60%**는 전혀 다른 압력을 시사합니다.
- **강세·약세·중립 비율:** 계약과 티커 전체 옵션 체인에서 계산한 센티먼트 분포
- **Sweep % / Multi-leg %:** 스윕과 복합 전략 관련 거래 비중
- **OI 변화:** 전일 대비 특정 계약의 미결제약정 증감. **높은 거래량 + OI 증가 + 한쪽 호가의 공격적인 체결**은 거래량만 높은 경우보다 신규 위험이 쌓이는 상황을 시사할 수 있습니다.
- **현물가격·OTM %·IV·DTE:** 현재 가격 대비 포지셔닝 맥락

즉 **특정 계약의 하루를 한 줄로 압축한 정보**입니다.

### Scanner는 언제 사용하나요?

질문이 개별 체결이 아니라 **계약 자체**에 관한 것일 때 유용합니다.

- **오늘 무엇이 활발했나요?** 프리미엄이나 거래 수로 정렬합니다.
- **어느 행사가에 새로운 포지션이 생겼나요?** OI 증가와 높은 거래량을 함께 봅니다.
- **어느 계약에 매수·매도 압력이 쏠렸나요?** Bid/Ask 비중과 계약 센티먼트를 필터링합니다.
- **과거에도 이런 거래가 있었나요?** 실적 발표 이전 날짜 등의 거래를 재검토합니다.
- **Live Feed에 없는 집계 필터가 필요하나요?** OI Growth, 계약·체인 센티먼트, OPEX Only, 행사가 범위 필터를 사용합니다.

Scanner의 목적은 빠르게 지나가는 체결에 즉각 반응하는 것이 아니라, **하루 전체의 계약별 활동을 비교**하는 것입니다.

### Scanner 행을 클릭하면

Scanner에서도 Live Feed와 동일한 **차트 모달**이 열립니다. 다만 행 자체가 여러 체결의 합계이므로 모달 아래의 **Flow Orders**를 열어 집계에 포함된 개별 체결을 보는 기능이 특히 유용합니다.

모달의 다섯 가지 차트, Discord 공유, 캔들 선택, 행사가 분포 확인은 동일합니다. 반면 캔들에서 **Expand Trades**로 새 Live Feed 탭을 여는 기능은 Scanner에 연결되지 않았다고 원문은 안내합니다.

## Flow Tracker: 나중에 관심 체결을 추적하기

**Tracker**는 중요하다고 생각해 북마크한 체결을 계속 보관하는 목록입니다. Live Feed처럼 흘러가 사라지지 않고, Scanner처럼 필터를 바꾼다고 결과가 달라지지도 않습니다. 여러 세션에 걸쳐 **처음 관심을 가졌던 특정 거래가 이후 어떻게 변했는지** 확인할 수 있습니다.

### 거래를 Tracker에 추가하는 방법

Live Feed에서 두 가지 방식이 있습니다.

1. 해당 행의 **별표(북마크) 아이콘**을 클릭합니다.
2. 행을 **우클릭 → Track Trade**를 선택합니다.

두 동작 모두 해당 체결을 계정에 저장합니다. 원문 기준으로 **Tracker 화면에서 수동으로 신규 추가하는 기능은 없습니다.**

> 🧠 **요약**  
> 체결 당시 눈길을 끌었던 거래는 나중에 다시 확인할 가치가 있습니다. 한 시간 뒤, 다음 날, 만기 전 또는 실적 발표 직전에 돌아와 보세요. Tracker는 이런 관찰 기록을 쌓는 곳입니다. 관련성이 없다고 판단되면 쉽게 삭제할 수 있습니다.

### Tracked Flow와 Tracked Contracts

Tracker 상단에는 두 탭이 있습니다.

- **Tracked Flow:** 개별 체결을 북마크한 목록입니다. 행 하나가 한 번의 체결을 뜻합니다.
- **Tracked Contracts:** Contract Drilldown의 북마크 또는 Flow Compass 카드에서 계약 자체를 저장한 목록입니다. **티커 + 행사가 + 만기 + 콜/풋** 조합으로 추적하며 현재 **Mid**와 **Spot**을 표시합니다.

### 데스크톱과 모바일 표시 방식

**데스크톱**은 좌우 분할 화면입니다. 왼쪽은 저장 당시의 체결 정보(시간·티커·행사가·계약 종류·만기·현물·프리미엄 등), 오른쪽 **약 500픽셀 패널**은 실시간 갱신 값입니다.

오른쪽에는 **Mid(현재 옵션 중간호가), Spot(현재 기초자산 가격), P/L %, P/L $, Status** 등이 표시됩니다. 시장 거래시간에 갱신되므로 관심 체결이 어떻게 움직이는지 계속 볼 수 있습니다.

**모바일**에서는 분할된 표 대신 **세로로 쌓인 카드**로 보여주며, 카드를 스와이프해 같은 정보를 볼 수 있다고 설명합니다.

### 대형 거래의 상태와 OI Drift

Tracker의 **Status**는 단순히 가격이 올랐는지 내렸는지 보여주는 값이 아닙니다. 후속 체결과 다음 날의 미결제약정을 참고해 **포지션이 유지 또는 청산된 것으로 추정되는지** 표시합니다. 계좌 거래내역을 직접 읽는 것이 아니므로 **누가 거래했는지 확정할 수 없습니다.**

- **STILL IN:** 청산 신호가 감지되지 않아 유지 중으로 추정
- **PENDING:** 당일 반대편의 큰 체결이 감지됨. 다음 날 OI 갱신으로 확인 또는 철회
- **PARTIAL N%:** 원문 모델상 N%가 청산된 것으로 추정
- **EXITED:** 포지션이 전부 청산된 것으로 추정
- **EXPIRED:** 포지션이 열려 있는 상태로 만기 도달

이러한 변화는 자동 감지되며 새 청산 신호가 발견되면 사이드바 Tracker 배지의 숫자가 증가한다고 설명합니다. 별도의 **OI Drift** 배지는 북마크 이후 해당 행사가의 미결제약정이 어떻게 변했는지 보여줍니다.

### 목록에서 제거하기

데스크톱에서는 행에 마우스를 올리고, 모바일에서는 카드 우측 상단을 찾아 **휴지통 아이콘**을 클릭해 삭제합니다. 제거는 즉시 적용되고 취소할 수 없지만, 해당 과거 체결을 Live Feed에서 다시 찾을 수 있다면 재북마크할 수 있다고 안내합니다.

## 공통 상세 화면: 차트 모달

세 페이지에서 체결을 클릭하면 동일한 **차트 모달(Chart Modal)**이 열립니다.

### 다섯 가지 차트

| 차트 | 보여주는 내용 |
| --- | --- |
| **Contract Flow** | Bid/Mid/Ask·분류되지 않은 거래량의 누적 막대, 계약 평균 체결가(VWAP) 선. IV 오버레이와 RVOL 기준선 선택 |
| **Underlying (Vol)** | 기초자산 가격과 구간별 옵션 거래량 |
| **Underlying ($)** | 기초자산 가격과 구간별 옵션 프리미엄 달러 규모 |
| **Net Premium** | 해당 티커의 **1·2·5일** 또는 더 긴 기간 누적 순프리미엄. 가격과 체결 흐름의 괴리 분석 |
| **Strike Distribution** | 행사가별 옵션 활동 분포. **1D·1W** 모드, 행사가 클릭 시 만기별 세부 내역 |

**데스크톱**에서는 Contract Flow가 왼쪽에 고정되고 오른쪽에서 나머지 네 차트를 선택할 수 있습니다. 옵션 계약 자체의 차트와 티커 전체 순프리미엄을 나란히 볼 수 있다는 장점이 있습니다.

**모바일**에서는 좌우 분할 대신 다섯 차트가 **가로 탭**으로 표시됩니다. 탭을 터치해 전환합니다.

### 모달 하단의 두 표

- **Flow Orders:** 해당 캔들을 구성하는 개별 체결 목록
- **Vol / OI History:** 최근 일자별 거래량과 미결제약정 기록

Contract Flow에서 캔들을 선택하면 하단의 **Expand Trades**가 활성화됩니다. Live Feed에서는 새 필터 탭을 만들지만 Scanner·Tracker에서는 이 기능이 연결되지 않았다고 설명합니다. **Clear Selection**으로 캔들 선택을 초기화할 수 있습니다.

### 모달 헤더의 명령

**Refresh**는 차트 데이터의 수동 새로고침이며 짧은 재호출 제한이 있습니다. **Share to Discord**는 구성된 채널에 차트 PNG와 거래 맥락을 보내며, 권한이 없는 계정은 업그레이드 안내가 나타날 수 있습니다. **Close(×)** 또는 **Escape**로 닫습니다.

## 세 페이지를 연결한 작업 흐름

원문은 다음 순서를 제안합니다.

1. **Live Feed를 엽니다.** 상단 요약 바와 실시간 체결 흐름으로 세션 분위기를 파악합니다.
2. **필터를 정합니다.** 스윕, 섹터 등 오늘 관심 있는 거래에 맞는 탭을 사용합니다.
3. **흥미로운 체결을 클릭합니다.** Net Premium·Strike Distribution 차트로 배경을 봅니다. 필요한 캔들은 Expand Trades로 개별 체결까지 확인합니다.
4. **나중에 볼 거래를 북마크합니다.** 필터와 구조적 맥락에 부합하는 거래를 Tracker에 저장합니다.
5. **약 한 시간마다 Tracker를 확인합니다.** 유지·부분 청산·청산 추정 상태의 변화를 살펴봅니다.
6. **장 마감 후 Scanner를 엽니다.** 오늘 날짜에서 프리미엄·OI 증가·Ask 측 체결·스윕 비율로 계약을 정렬해 하루 전체 패턴을 복기합니다.

**Live Feed는 실시간 읽기, Scanner는 계약별 복기, Tracker는 기억을 위한 도구**입니다. 세 가지를 연결해야 빠르게 흐르는 테이프를 무작정 바라보는 것보다 체계적인 분석이 가능합니다.

## 처음 사용할 때 해 볼 일

1. **Live Feed**에서 기본 탭의 이름을 바꾸고 복제해 두 탭을 만듭니다.
2. 첫 탭은 **프리미엄 100,000달러 이상 + 주식만**, 둘째는 **250,000달러 이상 + Sweeps Only + |Flow Score| > 50**으로 설정합니다.
3. **Columns**에서 불필요한 열을 숨기고 중요한 열을 왼쪽으로 옮깁니다.
4. 티커 검색에서 **`!SPY`**를 입력해 SPY 체결을 제외하고, 태그를 지워 원상복귀합니다.
5. 관심 있는 체결을 **북마크**하고 한 시간 뒤 Tracker에서 다시 봅니다.
6. 마감 후 Scanner에서 오늘 날짜를 선택하고 **프리미엄 기준으로 정렬**합니다. OI 증가·Ask 체결 비중·스윕 비율이 높은 계약을 살펴봅니다.

일주일 정도 반복하면 여러 페이지가 따로 노는 화면이 아니라 하나의 자연스러운 작업 흐름으로 느껴질 수 있습니다.

## 자주 묻는 질문

### Live Feed와 Scanner의 차이는 무엇인가요?

**분석 단위**가 다릅니다. Live Feed의 행 하나는 실시간 **개별 체결**입니다. Scanner의 행 하나는 **하나의 계약(티커·만기·행사가·콜/풋)**에 대한 당일 총프리미엄, 거래량, 호가 체결 구성, 센티먼트, OI 변화, 스윕 비중 등을 집계한 결과입니다. Live Feed는 “지금 무엇이 체결됐나”, Scanner는 “오늘 어느 계약이 중요했고 어떻게 거래됐나”에 답합니다.

### 거래를 추적한다는 것은 정확히 무엇인가요?

Live Feed에서 북마크한 체결이 계정에 저장됩니다. Tracker는 장중 **Mid, Spot, P/L %, P/L $**를 갱신하고 후속 체결·OI를 바탕으로 **STILL IN → PARTIAL → EXITED** 등의 상태를 추정합니다. 저장한 체결은 세션이 끝나도 남습니다. 다만 해당 투자자의 실제 계좌 상태를 확인하는 것은 아닙니다.

### 체결을 발견한 뒤 가장 빠르게 추적하려면 어떻게 하나요?

Live Feed에서 행의 별표를 클릭하거나 **우클릭 → Track Trade**를 선택한 후 사이드바의 **Tracker**로 이동합니다. 더 깊은 분석이 필요하다면 먼저 행을 클릭해 차트 모달의 Net Premium을 확인한 다음 닫고 북마크합니다. 몇 초를 더 써서 그 체결이 전체 흐름과 일치하는지 확인하는 편이 무작정 저장하는 것보다 유용할 수 있습니다.
