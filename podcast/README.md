# option101 오디오 클래스

운전·산책·이동 중 **화면 없이 들을 수 있도록** Skylit/options101 학습 내용을 재구성한 한국어 팟캐스트 시리즈입니다.

- **목표:** 45개 글의 내용을 낭독하는 대신 핵심을 이해할 수 있는 대화형 오디오 강의
- **회차 분량:** 기본 8~12분, 복습편 5분, 심화편 12~18분
- **진행:** 남녀 2인 대화형. 지훈(차분한 설명자)과 수아(초심자 질문자)가 비유→질문→설명→사례→복습→다음 화 예고 순서로 진행
- **독자:** 옵션 기초부터 GEX/VEX·딜러 포지셔닝·플로우까지 차근차근 배우려는 사람
- **운전 중 안전:** 화면을 보라는 지시 없이 듣는 설명에 집중. 실제 매매 및 차트 확인은 정차 후
- **출처:** [option101 한국어 문서](../docs/skylit/KO_INDEX.md), [금융 용어집](../TRANSLATION_GLOSSARY.md)
- **성격:** 원문을 그대로 낭독하지 않은 새 학습용 해설. 투자 조언이나 수익 보장 아님

## 2인 대화형 제작 규칙

- **지훈(남성 설명자):** 복잡한 개념을 차분하게 설명하고 비유·예시를 제시합니다.
- **수아(여성 질문자):** 청취자가 할 만한 질문, 흔한 오해, 반례를 제시하고 배운 내용을 자기 말로 요약합니다.
- 한 사람의 긴 독백보다 **짧고 자연스러운 문답**을 중심으로 합니다. 각 화에 실제 이해를 돕는 반문과 오해 정정 장면을 포함합니다.
- **매매 지시나 실시간 화면 확인을 유도하지 않습니다.** 종목·가격 예시는 가상임을 밝히고, 실제 시장의 모델 추정과 확정 사실을 구분합니다.
- 화자 이름은 대본에 표시하되 **음성 낭독에서는 생략**하고 서로 다른 음성으로 구분합니다.
- 대화가 형식적으로 들리지 않도록 질문자는 설명을 반복하는 데 그치지 않고 다른 각도에서 문제를 묻습니다.

시리즈는 **난이도에 따라 순서대로 듣도록** 구성합니다. 각 회차는 한 문장 핵심 요약과 최소 두 번의 복습을 포함하고, 표나 수식은 귀로 이해할 수 있는 한국어 문장으로 다시 씁니다.

## 오디오 게시 준비 상태

현재 첫 회는 **오디오 제작용 대본만 완료**됐습니다. 실제 MP3·M4A 파일과 팟캐스트 RSS 피드는 아직 생성하거나 배포하지 않았습니다.

휴대전화에서 안정적으로 재생하고 차량의 블루투스·CarPlay·Android Auto 오디오로 듣기 위해서는 자연스러운 한국어 TTS 또는 녹음으로 **오디오 파일을 먼저 만들어야** 합니다. 이후 MP3 파일을 호스팅하고 필요하면 팟캐스트 RSS 피드를 구성할 수 있습니다.

제작 시 권장 사항:

1. 한국어 TTS 음성이나 직접 녹음한 음성을 이용해 각 화를 실제 오디오 파일로 만듭니다.
2. 1~2초 멈춤, 작은 오프닝 음향, 일정한 음량을 적용합니다. 배경 음악 사용 시 저작권 확인.
3. 편집 뒤 **MP3 96~128kbps 모노** 또는 **M4A**로 출력합니다.
4. GitHub에 대본과 재생 링크를 게시하고, 오디오 파일은 용량 제한에 맞는 호스팅에 저장합니다.
5. RSS 팟캐스트 피드를 만들면 지원하는 팟캐스트 앱에 등록할 수 있습니다.
