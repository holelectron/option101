# option101 오디오 클래스

운전·산책·이동 중 **화면 없이 들을 수 있도록** Skylit/options101 학습 내용을 재구성한 한국어 팟캐스트 시리즈입니다.

- **목표:** 45개 글의 내용을 낭독하는 대신 핵심을 이해할 수 있는 대화형 오디오 강의
- **회차 분량:** 고정 제한 없음. 입문·복습은 약 8~12분, 어려운 개념은 15~25분 이상도 허용하고 이해 가능한 단위로 나눕니다. 내용의 완결성과 이해도를 시간보다 우선합니다.
- **진행:** 남녀 2인 대화형. 지훈(차분한 설명자)과 수아(초심자 질문자)가 비유→질문→설명→사례→복습→다음 화 예고 순서로 진행
- **독자:** 옵션 기초부터 GEX/VEX·딜러 포지셔닝·플로우까지 차근차근 배우려는 사람
- **운전 중 안전:** 화면을 보라는 지시 없이 듣는 설명에 집중. 실제 매매 및 차트 확인은 정차 후
- **출처:** [option101 한국어 문서](../docs/skylit/KO_INDEX.md), [금융 용어집](../TRANSLATION_GLOSSARY.md)
- **성격:** 원문을 그대로 낭독하지 않은 새 학습용 해설. 투자 조언이나 수익 보장 아님

## 2인 대화형 제작 규칙

- **지훈(남성 설명자):** 복잡한 개념을 차분하게 설명하고 비유·예시를 제시합니다.
- **수아(여성 질문자):** 청취자가 할 만한 질문, 흔한 오해, 반례를 제시하고 배운 내용을 자기 말로 요약합니다.
- 한 사람의 긴 독백보다 **짧고 자연스러운 문답**을 중심으로 합니다. 각 화에 실제 이해를 돕는 반문과 오해 정정 장면을 포함합니다.
- **매매 지시나 실시간 화면 확인을 유도하지 않습니다.** 종목·가격 예시는 가상임을 밝히고, 실제 시장의 모델 추정과 확정 사실을 구분합니다.
- 화자 이름은 대본에 표시하되 **음성 낭독에서는 생략**하고 서로 다른 음성으로 구분합니다.
- 대화가 형식적으로 들리지 않도록 질문자는 설명을 반복하는 데 그치지 않고 다른 각도에서 문제를 묻습니다.

시리즈는 **난이도에 따라 순서대로 듣도록** 구성합니다. 각 회차는 한 문장 핵심 요약과 최소 두 번의 복습을 포함하고, 표나 수식은 귀로 이해할 수 있는 한국어 문장으로 다시 씁니다.

## 오디오 게시 준비 상태

첫 회 대본과 **남녀 두 음성 합성·MP3 제작 자동화**를 GitHub에 구성했습니다. 음성 제작은 GitHub Actions의 [Render Korean option101 podcast](https://github.com/holelectron/option101/actions/workflows/render-option101-podcast.yml)에서 실행합니다. 작업이 성공하면 `docs/public/podcast/ep01.mp3`에 음성 파일을 커밋하고 GitHub Pages 배포가 이어지도록 설계했습니다. **MP3 및 RSS 피드의 실제 배포 여부는 워크플로 실행 결과를 확인해야 합니다.**

휴대전화에서 안정적으로 재생하고 차량의 블루투스·CarPlay·Android Auto 오디오로 듣기 위해서는 자연스러운 한국어 TTS 또는 녹음으로 **오디오 파일을 먼저 만들어야** 합니다. 이후 MP3 파일을 호스팅하고 필요하면 팟캐스트 RSS 피드를 구성할 수 있습니다.

현재 제작 방법:

1. `scripts/render_option101_podcast.py`가 `**지훈:**` 및 `**수아:**`로 시작하는 대사만 읽고 두 한국어 음성(`ko-KR-InJoonNeural`, `ko-KR-SunHiNeural`)을 순서대로 합성합니다.
2. 음량을 맞춘 뒤 화자 사이에 약 0.34초, 새 절에서는 약 0.85초 쉬는 구간을 넣고 **112kbps 모노 MP3**로 합칩니다.
3. GitHub Actions가 파일을 아티팩트로 올리고 `docs/public/podcast/ep01.mp3`에 커밋하면 Pages에서 재생·다운로드할 수 있습니다.
4. **미리듣기**는 workflow_dispatch의 `preview=true`를 사용하면 첫 4개 대사만 처리합니다.
5. `edge-tts`는 공식적으로 보장된 API가 아니라 외부 온라인 음성 서비스에 의존합니다. 차단·서비스 변경·음질 문제가 생길 수 있으므로 결과를 반드시 들어보고 검수합니다. 음악은 포함하지 않습니다.
6. 모든 회차를 완성하면 팟캐스트 RSS와 장시간 자동 재생 목록을 별도로 구성합니다.

> 공개 배포 전 Skylit 콘텐츠의 이용 조건을 확인하고, 원문 전체를 무단으로 그대로 낭독하지 않습니다.
